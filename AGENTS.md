# Winteria DAW: правила для ИИ-помощников

Над этим проектом работают **два помощника**:

- **ChatGPT (Codex)** собирает и подписывает APK, выкладывает обновления.
- **Claude (Anthropic)** делает мобильный интерфейс, чинит сборку и сбои, настроил CI.

Владелец проекта — пользователь (GitHub `dozyFJ` / `ffight763-glitch`). Мы работаем по очереди в одном
репозитории, поэтому договорённости такие:

## Где что лежит

- Репозиторий: https://github.com/ffight763-glitch/Vinteria-git3 (публичный, GitHub Actions бесплатные).
- Ветки:
  - `winteria-chatgpt`: работа ChatGPT.
  - `winteria-mobile-pulse`: работа Claude.
  - Общая линия после объединения будет `winteria`.
- План работ: `ROADMAP.md` (общий список, отмечайте сделанное).
- Заметки друг для друга:
  - `CHATGPT_HANDOFF.md`: от Claude для ChatGPT.
  - `CLAUDE_HANDOFF.md`: от ChatGPT для Claude, а также журнал версий в ветке Claude.
- Обновления (OTA): сейчас `dozyFJ/pulse-updates`, ветка `winteria` (`latest.json` + `releases/Winteria-<версия>.apk`).

## Правила

1. **Всё пушить.** Любая версия, которую получает пользователь, должна иметь свой коммит в этом репозитории.
   Номер коммита пишем в `sourceCommit` в `latest.json`. Код, который есть только в облачной папке, второй
   помощник не увидит.
2. **Никаких секретов в git:** ни `*.keystore` / `*.jks`, ни паролей, ни токенов. Ключ подписи хранится у
   пользователя или в секретах GitHub (`ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`).
3. **Номер версии:** берём следующий после последнего опубликованного кем угодно (смотри `latest.json` и релизы
   этого репозитория), чтобы номера не пересекались.
4. **Перед работой:** `git fetch --all`, прочитать свежие заметки, начать от последней общей версии.
5. **После работы:** пушнуть ветку и дописать в заметку для второго помощника, что сделано, что не проверено и
   что дальше.
6. **Перед выпуском APK** проверить, что в библиотеке нет неразрешённых C++ символов (`tools/build-android.sh`
   делает это сам). Иначе приложение падает на старте с `__cxa_pure_virtual`.
7. **Чужие сэмплы и пресеты** (купленные или «слитые» паки) в репозиторий и APK не кладём. Только свои звуки или CC0.
8. **Дизайн:** на ПК остаётся стиль AOS, на телефоне свой, в стиле Pulse (портрет, стекло). Десктоп не ломать
   ради телефона.
